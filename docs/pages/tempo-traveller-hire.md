# Tempo Traveller Hire page

## Implementation

- Route: `/tempo-traveller-hire` in `routes/web.php`
- Blade view: `resources/views/pages/tempo-traveller-hire.blade.php`
- Page stylesheet: `public/css/pages/tempo-traveller-hire.css`
- Served directly from `public/css/pages/tempo-traveller-hire.css`

The Blade body and page-specific stylesheet are intentionally empty so page content and styling can be added later. The view includes the shared stylesheet and this page's dedicated stylesheet.

The blank main content area reserves a viewport-height space so the shared [header](../components/header.md) and [footer](../components/footer.md) remain separate until page content is added. The Home and About page navigation links point to this route.
