# UI design

The Bento Grid design system applies to the admin panel only: login, dashboard, blog, email, and contact-submission screens use `public/css/admin.css` with responsive cards, admin tokens, light/dark mode, focus states, and status feedback.

Public frontend pages follow the existing Make My Tours & Travels theme: Heebo body text, Barlow headings, orange accents, image banners, custom page styles, and the shared header/footer. Public blog listing, category, tag, and detail views use the shared header and footer, site fonts, and a scoped blog stylesheet. The listing banner follows the inner-page image treatment, dark overlay, breadcrumb, and responsive spacing. Blog-specific styles must stay scoped to the blog layout and preserve accessible labels, keyboard focus, and mobile reflow. Public pages do not use admin or Bento styling.
