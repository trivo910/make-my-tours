# UI design

The Bento Grid design system applies to the admin panel only: login, dashboard, blog, email, and contact-submission screens use `public/css/admin.css` with responsive cards, admin tokens, light/dark mode, focus states, and status feedback.

Public frontend pages follow the existing Make My Tours & Travels theme: Heebo body text, Barlow headings, orange accents, image banners, custom page styles, and the shared header/footer. The public contact page uses those frontend conventions in `public/css/contact.css`; it does not use admin or Bento styling. Preserve accessible labels, keyboard focus, and mobile reflow across both areas.
