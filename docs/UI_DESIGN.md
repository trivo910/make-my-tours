# UI design

Admin login, dashboard, blog, email, and contact screens use the Bento card system in `public/css/admin.css`: responsive CSS grids, rounded surfaces, shared design tokens, light/dark mode, focus states, and compact status feedback. Public contact is styled in `public/css/contact.css` and follows the site header/footer. Preserve accessible labels, keyboard focus, mobile reflow, and the saved theme preference when extending these screens.
