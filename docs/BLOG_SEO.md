# Blog and SEO

Manage posts and categories at `/admin/blog` and `/admin/blog-categories`. Public listing, category, tag, post and sitemap routes expose only published content whose `published_at` is due. Publication dates use the application timezone (`APP_TIMEZONE`, default `Asia/Kolkata`), including the admin's local date-time input. Slug history supports permanent redirects. Post metadata and structured data are rendered by the public blog views. Blog media is stored on the public disk; after deployment run `php artisan storage:link` and ensure the host has Fileinfo support. GD with WebP support is optional and enables image resizing and WebP conversion.
